## 3. 역할 사이의 약속

- 역할끼리는 함수 호출이 아니라 **DB 테이블**로 연결된다. 그래서 각 역할은 다른 역할의 진행과 상관없이 개발할 수 있다.
  - 역할 1은 `clean_news`를 채운다.
  - 역할 2는 `clean_news`를 읽어 `summaries`·`analyses`를 채운다.
  - 역할 3은 읽기만 한다.
- 테이블 컬럼을 바꾸려면 `docs/설계서.md` 3절을 먼저 고치고 팀에 알린다.
- 제출용 저장소의 커밋은 **팀장 계정으로 단계별로 나눠** 올린다(설계 → 수집 → 정제 → AI → 출력·조회 → 테스트 → 문서·결과). 그래서 커밋 작성자는 팀장 한 명이다. 역할 담당은 1절 표와 같다.
